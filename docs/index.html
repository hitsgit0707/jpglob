VoltEdge — Electrical Engineering Calculator

A desktop graphical application built in Core Java (Java 17) and Java Swing.

Desktop Application Notice: VoltEdge is an offline desktop Java Swing application. It runs locally on the Java Virtual Machine (JVM) and is not executed inside the web browser.

Calculators Included

  • 1. Ohm's Law V = I · R | I = V / R | R = V / I
  • 2. Electrical Power P = V · I | P = I² · R | P = V² / R
  • 3. Resistor Networks Series summation & parallel reciprocal equivalent
  • 4. Voltage Divider Vout, voltage drops, and series current
  • 5. Capacitor Networks Parallel direct sum & series reciprocal storage
  • 6. Unit Converter Scale factors for V, A, Ω, F, W, and Hz
  • 7. Calculation History Persistent local audit log with clear option

Running the Desktop Application

Compile and launch using standard Java 17 tools from the repository root:

javac -d app/bin $(find app/src -name "*.java")
java -cp app/bin voltedge.Main
